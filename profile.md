# GitHub Profile README 配置指南

> 这是一个可直接使用的 GitHub Profile README 模板集合

---

## 📋 快速开始

1. 创建一个与 GitHub 用户名相同的仓库（如 `pureey/pureey`）
2. 设置为 **Public** 仓库
3. 勾选 **Add a README file**
4. 将下方代码复制到 README.md 中
5. 替换所有占位符（如 `pureey`、`your.email@example.com` 等）

### GitHub Stats
```markdown
![GitHub Stats](https://github-readme-stats.vercel.app/api?username=YOUR_USERNAME&show_icons=true&theme=tokyonight&hide_border=true)
```

**可选参数**:
| 参数 | 说明 | 示例值 |
|------|------|--------|
| `show_icons=true` | 显示编程语言图标 | `true` / `false` |
| `theme` | 主题名称 | `tokyonight`, `dracula`, `monokai` |
| `hide_border=true` | 隐藏边框 | `true` / `false` |
| `count_private=true` | 包含私有仓库 | `true` / `false` |
| `include_all_commits=true` | 包含所有提交 | `true` / `false` |
| `hide` | 隐藏特定项目 | `hide=stars,prs_merged` |

### GitHub Actions 自动更新统计

创建 `.github/workflows/update-readme.yml`:

```yaml
name: Update README Stats
on:
  schedule:
    - cron: '0 * * * *'  # 每小时更新一次
  workflow_dispatch:       # 手动触发

jobs:
  update-readme:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - uses: actions/github-profile-trophy@v1
        with:
          USERNAME: ${{ github.repository_owner }}
          THEME: tokyonight
      
      - uses: lowlighter/metrics@latest
        with:
          template: markdown
          filename: metrics.md
          options: template,terminal,achievements
          user: ${{ github.repository_owner }}
          theme: tokyonight
```

## ⚠️ 注意事项

1. **用户名替换**: 所有 `YOUR_USERNAME` 替换为你的 GitHub 用户名
2. **API 限制**: 免费 API 有请求限制，高流量可能暂时不可用
3. **主题一致性**: 建议所有卡片使用相同主题
4. **图片加载**: 部分服务（如 GitHub Profile Trophy）可能需要科学上网
5. **更新频率**: 统计卡片通常有缓存，实时更新可能需要等待
